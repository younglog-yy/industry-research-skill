# industry-research-skill

`industry-research` 是一个面向行业研究与买方投研场景的开源 Skill。它将行业研究拆解为“确定口径—规划检索—建立事实底座—产业与供需分析—市场空间测算—公司与估值比较—事实核验—风险跟踪”的标准化工作流，帮助通用模型生成结构清晰、数据可追溯、结论可证伪的行业研究报告。

它不是固定目录模板，也不承诺用模型替代研究员。它通过来源优先级、数据属性分层、增速反算、证券代码校验、口径检查和证据不足降级等规则，减少行业报告中的事实混淆、计算错误与虚假确定性。

Skill 默认可以独立运行。金融数据库、行情接口以及 Wind Alice 等专业能力均为可选增强项，不是安装或使用本 Skill 的前置条件。

## 核心能力

- 标准化行业研究工作流，并允许按需执行单个模块。
- 根据行业属性选择专属指标、供需变量和估值方法。
- 将实际值、机构预测、本报告测算和观点严格分层。
- 要求关键数字提供直接来源链接、发布日期和统计口径。
- 强制检查增速、版本、单位、证券代码和主体归属。
- 数据不足时允许留空、降级或标记“待验证”，不为完整性编造数字。
- 用可量化风险、证伪条件和跟踪指标约束研究结论。

## 快速上手

将仓库中的 `SKILL.md` 安装到支持 Skills 的 Agent 后，直接输入行业名称即可：

```text
使用 industry-research 研究半导体行业。
```

更完整的请求示例：

```text
使用 industry-research 生成中国半导体设备行业深度报告，
数据截至最新可得日期，预测到 2030 年，
覆盖产业链、供需、市场空间、竞争格局、重点公司和风险跟踪。
```

只研究一个模块也可以：

```text
使用 industry-research 分析储能行业的供需关系和未来三年市场空间，
不用生成完整报告。
```

快速扫描示例：

```text
使用 industry-research 对中国创新药行业做一次快速扫描，
重点回答行业目前处于什么阶段、主要驱动因素和风险是什么。
```

## 工作流

1. 确定研究范围、地域、时间基准、统计口径和目标读者。
2. 规划研究问题、所需数据、优先来源和工具路由。
3. 建立带来源、日期、口径和属性的事实底座。
4. 分析产业链、供需、竞争格局、技术和政策变量。
5. 使用可复算的 Top-down 与 Bottom-up 方法测算市场空间。
6. 筛选公司、校验证券主体并统一财务与估值口径。
7. 对高影响事实和计算结果执行核验与冲突处理。
8. 输出投资逻辑、风险矩阵、证伪条件和跟踪指标。

## 数据真实性规则

- 真实性高于完整性。无法核验的数据可以留空，不得猜测补齐。
- 关键数字必须附直接来源链接、发布日期、数据期和统计口径。
- 搜索摘要、模糊的机构名称和未提供原文的转述不能单独支撑强结论。
- 实际值、机构预测、本报告测算和观点必须明确区分。
- 市场规模、份额、国产化率、供需缺口、行情和估值属于高风险数据，必须专项核验。
- 未通过核验的内容不得进入摘要、核心结论或推荐逻辑。

报告质量取决于宿主模型能够访问的数据和工具。本 Skill 规定研究流程、数据准入和核验规则，但不自带金融数据库，也不能保证所有实时数据均可获得。当关键数据缺少来源、日期或统计口径时，应降低结论强度或标记“待验证”。

## 运行模式

| 模式 | 所需能力 | 适用场景 |
|---|---|---|
| 基础模式 | 仅 `industry-research` 与宿主已有检索工具 | 通用行业扫描、框架研究和公开资料分析 |
| 数据增强模式 | 任意金融数据库、行情或财务接口 | 提升财务、行情、证券与估值数据质量 |
| 专业校验模式 | 可选的市场测算、Comps 或事实核验工具 | 生成第二套模型并复核高影响结论 |

如果环境中没有外部专业工具，Skill 应继续完成核心工作流，并对证据缺口降级处理；只有用户明确要求某项增强能力时，缺少该能力才需要提示。

## 推荐输入

为了得到更稳定的结果，可以在请求中补充：

- 行业与细分环节；
- 地域范围；
- 数据截止日期；
- 历史期与预测期；
- 重点问题；
- 公司或上市市场范围；
- 输出深度与用途。

如果这些信息缺失，Skill 会采用合理默认值；只有行业边界会显著改变结论时才追问。
